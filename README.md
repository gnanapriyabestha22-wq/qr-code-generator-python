# 📱 QR Code Generator

A simple and user-friendly **QR Code Generator** built using **Python and Tkinter**. This application allows users to enter text, URLs, or contact information and generate a QR code that can be saved as an image.

## ✨ Features

* 🔲 Generate QR codes
* 🌐 Generate QR codes for URLs
* 📝 Convert text into QR codes
* 👤 Add contact information
* 💾 Save QR codes as image files
* 🧹 Clear input and generated QR code
* 🖥️ Simple graphical user interface
* ⚠️ Input validation
* 🖼️ QR code preview

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter** – GUI development
* **qrcode** – QR code generation
* **Pillow (PIL)** – Image handling

## 📦 Installation

First, make sure Python is installed:

```bash
python --version
```

Install the required libraries:

```bash
python -m pip install "qrcode[pil]"
```

## 📖 How to Use

1. Open the application.
2. Enter text, a URL, or contact information.
3. Click **Generate QR**.
4. The QR code will appear in the preview area.
5. Click **Save QR**.
6. Choose a location and filename.
7. Your QR code will be saved as an image.
